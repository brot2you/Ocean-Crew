OCEAN CREW — BROT2YOU V1
Ouvrez index.html dans un navigateur pour utiliser l'application, même hors connexion.
Pour publier : décompressez le ZIP, déposez index.html à la racine d'un dépôt GitHub Pages.
Les données sont sauvegardées localement dans le navigateur. Utilisez Exporter régulièrement pour conserver un fichier JSON, puis Importer pour restaurer les données sur un autre appareil.
Une séance nouvellement créée démarre avec 3 cœurs par équipage (5 points), modifiables pendant le cours. Seules les séances validées entrent dans le total cumulatif.
